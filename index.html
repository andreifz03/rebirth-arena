How It Works
Post-Match Processing
API PENDING
Once Riot API access is connected, Rebirth Arena will analyze each completed match in chronological kill order. It identifies your exact 10th, 20th, 30th kill and awards +1 progression to the enemy agent eliminated on that milestone kill.
1
Match completes
Only completed match data is used.
2
Your kills are ordered
The app counts your eliminations chronologically: #1, #2, #3 ... #10, #20, #30.
3
Milestone victim is identified
If your kill #10 is Reyna, Reyna gets +1. If kill #20 is Omen, Omen gets +1.
4
Agent progression updates
Each enemy agent has separate progress. 5 milestone points on the same enemy agent advances that agent one Rebirth tier.
Core Rule
Who Gets The Point?
Your own VALORANT agent is not the progression target. Rebirth Arena looks only at which enemy agent you eliminated on your milestone kill.
